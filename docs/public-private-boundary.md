# Public / private boundary

The public repository is downstream of a fail-closed sanitizer/exporter in private `GENESIS-Δ-λ-n`.

## Publicly admissible

- lineage identifiers and public ancestry edges;
- sanitized birth certificates;
- aggregate topology/capacity/dynamics metrics;
- public state and event roots;
- public-safe runtime/manifest commitments;
- protocols, gate outcomes and claim boundaries;
- public milestone chronology.

## Private by default

- raw state/checkpoint binaries;
- full event archives and event payloads;
- private topology/edge identities;
- private developmental/genome parameters;
- inheritance/mutation/selection implementation;
- private corpora and raw sensory records;
- private source code and local storage topology.

## Export rule

No file moves from private to public by manual copy/paste when a canonical exporter exists. The exporter should emit a schema-versioned object, validate an allowlist of fields, reject forbidden key patterns and produce a digest that can be recorded in both repositories.

A public root commits to private data without making the private data public.
