# Methodology

GENESIS-Δ-λ separates two research modes that must never be conflated.

## Reset experiments

Fresh canonical baselines are used for controlled, preregistered comparisons, ablations and causal tests.

```text
S0 → treatment
S0 → control A
S0 → control B
```

These runs maximize causal interpretability and reproducibility.

## Longitudinal lineages

A named lineage preserves canonical ancestry across time:

```text
Birth → S1 → S2 → ... → Sn
```

These runs answer different questions: developmental drift, accumulation, long-horizon plasticity, migration continuity and later lineage-level inheritance.

## Rule

A longitudinal lineage is never used as a substitute for reset controls. Reset controls are never described as the historical continuation of a lineage.

## Public evidence

Public reports should expose the minimum information needed to evaluate the declared claim: protocol identifier, lineage/state identifiers, cryptographic roots, aggregate observables, gate outcome and explicit non-claims.

Unknown or unlogged history is labeled unknown rather than reconstructed from expectation.
