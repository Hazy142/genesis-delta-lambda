# Security and disclosure policy

This public repository is intentionally separated from private GENESIS research state.

## Do not disclose here

- credentials, cookies, tokens or machine secrets;
- private repository source;
- raw substrate/checkpoint binaries;
- private Authority event payload archives;
- raw private corpora or source documents;
- source edge identities or full private topology dumps;
- unpublished developmental, inheritance or selection parameters;
- host-local absolute paths that reveal private storage layout.

If a public export is suspected to contain private material, stop publication, preserve the private source artifact unchanged, and replace the public artifact only through an explicit amendment that records what was withdrawn and why.

Public state roots are commitments, not invitations to publish their preimages.
