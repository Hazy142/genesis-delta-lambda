# G-D-L-1 milestones

Each milestone should be a small, human-readable report linked to one or more public state-root records.

Recommended filename:

```text
YYYY-MM-DD-<milestone-id>.md
```

A milestone must state:

- lineage/state identifiers;
- protocol or migration identifier;
- public-safe evidence commitments;
- observed aggregate changes;
- gate result;
- explicit non-claims;
- amendment links when later corrected.
