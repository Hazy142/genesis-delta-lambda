# AGENTS.md — GENESIS-Δ-λ public observatory

These instructions apply to every automated or human contributor operating in this repository.

## Mission

Maintain an IP-safe, scientifically conservative, cryptographically anchored public record of GENESIS lineage research.

## Hard boundaries

1. Never add private `rsgt-genesis` source code or unpublished implementation details.
2. Never add raw canonical substrate snapshots, CUDA/VRAM dumps, model/state binaries, raw Authority event payload archives, private corpora, credentials or machine-local paths.
3. Never publish source edge identities, private developmental parameters, private genome manifests or reproduction operators.
4. `G-D-L-n` always means a concrete canonical Authority lineage. It never means a software release.
5. Public records must be derived from an explicit sanitized export contract and remain independently hash-verifiable.
6. Do not silently upgrade research metaphors into claims. `edge of chaos`, `evolution`, `genome`, `phenotype`, `brain area` and similar terms require an operational definition in the relevant document.
7. Never claim consciousness, sentience, AGI, biological equivalence or self-organized criticality from topology, replay, recurrence or performance alone.
8. Existing implementation repositories are references, not writable dependencies from this repository.

## Change discipline

- Prefer append-only public lineage records and milestone documents.
- Correct errors explicitly; do not rewrite historical evidence without leaving an amendment trail.
- Every public evidence record should identify its schema version, lineage, state/milestone identifier and cryptographic commitment.
- Keep public files small and reviewable. Large artifacts belong outside Git and are represented only by public commitments where disclosure is safe.

## Allowed content

Architecture-level descriptions, sanitized aggregate metrics, public state roots, birth/ancestry certificates, public protocols, non-sensitive plots/tables, claim boundaries, public experiment summaries and reproduction instructions that do not reveal private implementation.
