# Inheritance experiments

This track remains inactive until at least one canonical parent lineage and an explicit reproduction contract exist.

Inheritance experiments test what, if anything, may cross from parent evidence into a new lineage's birth manifest.

The default rule is conservative:

- lifetime memories are not automatically inheritable;
- parent canonical state is not copied wholesale into offspring;
- every inherited field must be allowlisted and justified;
- variation, selection and inheritance are separate operations;
- a new lineage receives a new identity even when closely related to its parent.

Public reports expose only sanitized ancestry and aggregate inheritance descriptors.
