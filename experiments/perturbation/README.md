# Perturbation experiments

Perturbation protocols apply standardized, bounded interventions to a known lineage state and measure the resulting response.

The canonical lineage should normally remain untouched while the intervention runs on a clone unless the protocol explicitly defines a safe canonical exposure.

Candidate observables include response amplification, recovery time, context retention, topology-local effects, activity half-life and boundedness.

A perturbation result must never be interpreted as proof of criticality without an explicit null model and operational criterion.
