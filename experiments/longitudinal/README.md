# Longitudinal experiments

This track studies change **within the same canonical lineage** across time.

Examples:

- repeated standardized perturbation at different developmental ages;
- topology/capacity utilization trajectories;
- replay and recovery continuity;
- substrate migration continuity;
- long-horizon plasticity and developmental drift;
- recurrent-dynamics observables once explicitly implemented.

Every longitudinal protocol must identify the exact lineage/state range and distinguish historical observation from controlled reset comparisons.
